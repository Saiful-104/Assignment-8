## 🚀 About The Project

**HERO.IO** is a modern web application that allows users to **browse, search, and explore a collection of applications**.  
Users can view app details like downloads, ratings, reviews, and size.  
The app supports **real-time search with loading animations**, app installation using local storage, and a responsive design for both desktop and mobile devices.



## 🔥 Features

- Browse all apps in a **responsive grid layout**.  
- **Real-time search** with loading animation.  
- View **app details**: downloads, ratings, reviews, description, and size.  
- Install apps using **local storage**.  
- **Uninstall apps** from the installation page.  
- Responsive design with **hover animations** and smooth UI.  
- Rating distribution chart with **Recharts**.  


## 🛠 Technologies Used

- **Frontend:** React.js  
- **Styling:** Tailwind CSS  
- **Routing:** React Router  
- **Icons:** React Icons  
- **Charts:** Recharts  
- **Notifications:** React Toastify  
- **Local Storage** for installed apps  
- **Other:** Debounced search for better performance
